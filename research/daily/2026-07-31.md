### PHP 8.6 `list()` Deprecation Backlash
*   **Fact:** The RFC vote closes today. [Source: PHP Internals]
*   **Community Opinion:** Massive resistance from the WordPress and legacy CMS communities due to the refactoring burden. [Source: Reddit r/laravel]
*   **Engineering Impact:** If passed, it will trigger the largest automated migration event in PHP history via Rector/ast-grep.
*   **Business Impact:** High maintenance overhead for legacy enterprise systems.

### Laravel LSP (First-Party Language Server)
*   **Fact:** Announced at Laracon US 2026. [Source: Laravel News]
*   **Engineering Impact:** Deep integration with IDEs (VS Code, PhpStorm) providing framework-specific static analysis that generic LSPs miss.
*   **Business Impact:** Increased developer productivity and fewer framework-level bugs in production.

## Engineering Decisions

*   **Adopt `monthly` Log Driver:** Use in low-traffic Laravel 13.23+ apps to prevent directory bloat.
*   **Implement `->using()` for PGSQL:** Mandatory for PostgreSQL type casts in migrations to avoid "cannot be cast automatically" errors.
*   **Migrate to Inertia DevTools:** Replace community inspectors with the official Chrome extension for better prop tracking.
