# Daily Engineering Research

**Date:** 2026-07-25

---

## Executive Summary

*   **Laravel 13 Released:** The latest major version is now stable, introducing optional PHP attributes for models, middleware, and queues, significantly cleaning up class definitions.
*   **AI Agent Dominance:** Claude Code has become the #1 AI coding tool in just eight months, overtaking GitHub Copilot and Cursor in professional engineering workflows.
*   **PHP Internals Innovation:** A new `extension` keyword is being proposed for PHP, allowing developers to add methods to classes they don't own (Swift-style) and potentially to scalars.
*   **Backend Architecture Shift:** High-performance systems are moving toward "AI-native" backends, integrating vector databases and agentic orchestration directly into the core service layer.
*   **SaaS Evolution:** The "AI Wrapper" era is ending; successful 2026 startups are building "Vertical Automation" tools that handle end-to-end business processes rather than just generating text.
*   **Career Trends:** Staff+ engineers are the heaviest users of AI agents (63.5% adoption), using them for repository-wide refactoring and complex bug diagnosis rather than simple code completion.
*   **GitHub Momentum:** Open-source coding agents like OpenCode and Gemini CLI are seeing explosive growth, reflecting a trend toward model-flexible, local-first development tools.

## Laravel

### Important Updates
*   **Laravel 13 Stable:** Released March 17, 2026. Key focus on **PHP Attributes** to replace older property-based syntax in Queues, Models, and Controllers.
*   **Laravel AI SDK:** Now officially stable. It provides a first-party way to integrate LLMs with Laravel's native features like jobs and notifications.
*   **Starter Kits:** Jetstream-style "Teams" functionality has returned to all starter kits with improved multi-tab support and native **Passkey** integration.

### Interesting Discussions
*   **RouteKey Model Attribute:** Laravel 13.21 introduced a dedicated attribute for customizing model binding keys directly on the property.
*   **First-Party Image Processing:** New `Illuminate\Image` component provides a fluent, driver-agnostic API for image manipulation, reducing dependency on Intervention Image for basic tasks.

### Useful Packages
*   **Laravel Time Machine:** A request lifecycle profiler that allows developers to "rewind" and inspect the state of any service at any point in the request.
*   **Laravel SMS Catcher:** A local dashboard for debugging SMS notifications, similar to Mailpit but for mobile messaging.
*   **Polyscope:** An agent-first development environment specifically tuned for Laravel's directory structure and service container.

## Backend Engineering

### Interesting Articles
*   **"Systems That Scale in 2026":** Deep dive into how backend teams are selecting frameworks based on **throughput, extensibility, and AI readiness**.
*   **ZTS (Zend Thread Safety) by Default:** PHP internals discussion on making ZTS the default build to simplify maintenance and support modern runtimes like FrankenPHP.

### Architecture Discussions
*   **The Rise of Edge-Native Backends:** Moving business logic closer to the user using WASM and globally distributed databases to achieve sub-10ms latency.
*   **Event-Driven Evolution:** Heavy adoption of `Bus::batch()` style orchestration for complex, multi-step asynchronous pipelines in high-volume systems.

### Performance & Security
*   **PHP 8.6 Deprecations:** The list is frozen for the upcoming release, focusing on cleaning up legacy engine behaviors to improve execution speed.
*   **Schema-First Contract Validation:** A growing trend in building "bulletproof" APIs where the schema is the source of truth for both documentation and runtime validation.

## AI for Engineers

### New Tools
*   **Claude Code:** The current market leader for terminal-based repository reasoning and autonomous bug fixing.
*   **Codex CLI:** OpenAI's response, offering deep integration with the broader ChatGPT ecosystem and cloud-based code review.
*   **OpenCode:** The leading open-source alternative, allowing engineers to swap models (GPT-5, Claude 4, etc.) to avoid vendor lock-in.

### Useful Workflows
*   **Agentic Refactoring:** Using agents to perform repository-wide upgrades (e.g., migrating Laravel 12 to 13) by providing the documentation as context.
*   **Voice-Driven DevOps:** Demonstrations at Laracon EU showed engineers fixing production bugs and deploying via voice commands through agentic orchestration.

### Automation Ideas
*   **Self-Healing CI/CD:** Integrating agents into the CI pipeline to automatically propose fixes for failing unit tests.
*   **Documentation-to-Code:** Using agents to keep READMEs and API docs in sync with implementation changes in real-time.

## SaaS

### Interesting Startup Ideas
*   **Vertical Automation SaaS:** Tools specifically for niche industries (e.g., "AI Lawyer for Construction") that handle the entire workflow from document intake to filing.
*   **Micro-SaaS for AI Governance:** Small, focused tools that help companies monitor and limit the "hidden" token costs and security risks of their internal AI agents.

### Business Lessons
*   **Usage-Based Billing Dominance:** Most SaaS platforms have moved away from flat seats to "AI Credit" models, reflecting the variable cost of compute.
*   **Community-Led Growth:** Successful 2026 founders are focusing on building "local-first" tools that win over developers before moving to enterprise tiers.

*   **The "Agent-Fluent" Engineer:** Companies are specifically looking for developers who can demonstrate high productivity using AI agents for complex system design.
*   **Architecture over Syntax:** As AI handles more boilerplate, the value of a Senior Engineer has shifted almost entirely to system architecture and business logic.
