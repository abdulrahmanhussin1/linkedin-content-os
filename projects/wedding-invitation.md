# 🚀 Project Case Study: Wedding Invitation Platform

---

## 📖 Overview
An interactive digital wedding invitation platform featuring responsive animations, details, RSVP tracking, and smooth API integrations.

---

## 💼 Business Problem
Couples need a scalable, high-performance web interface to share wedding details and collect RSVP responses efficiently without relying on paper cards.

---

## 🛠️ Technical Problem
Fusing React, TypeScript, and Tailwind CSS in a monorepo workspace to build a fast-loading, highly responsive frontend that integrates with backend RSVP endpoints.

---

## 🏗️ Architecture
* **Paradigm**: Monorepo Workspace (PNPM), Decoupled Frontend
* **Design Patterns**: Component-based layout, API client abstractions

---

## 💻 Tech Stack
* **Languages**: TypeScript, JavaScript, HTML, CSS
* **Frontend Library/Tooling**: React, Vite
* **Styling**: Tailwind CSS
* **Package Manager**: PNPM Workspace
* **Hosting**: Vercel

---

## ⚠️ Challenges
* **Multi-device Layouts**: Developing interactive modules that adjust to mobile devices, tablets, and desktops.
* **Integrations**: Syncing client RSVP actions with backend storage endpoints without state delay.
